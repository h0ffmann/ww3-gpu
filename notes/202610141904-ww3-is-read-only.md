# WW3 is read-only

The `WW3/` submodule and `$WW3` are references: "Neither is edited from here" (`AGENTS.md`)
`(v)`. No WW3 source is copied into the repository, and every statement about WW3 cites
`model/src/<file>.F90:<line>` at the pinned commit. The only Fortran added is a shim behind a switch.

A port translates that code and does not improve it, which is why
[[202610141900-bit-for-bit-is-the-gate]] can hold. The code it translates has an end date:
[[202610141906-ww3-has-a-scheduled-end]].
