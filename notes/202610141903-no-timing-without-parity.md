# No timing without parity

A number of seconds says nothing about a kernel that gives a different answer. So "nothing timed
enters a table without a passed L1 on the same build" (`AGENTS.md`) `(v)`, and the timing names
the machine, the command and the median of three runs.

The L1 test is the gate of [[202610141900-bit-for-bit-is-the-gate]]. A timing of a kernel that
still copies per call is not the model's speed: [[202610141905-phase-one-copies-per-call]].
