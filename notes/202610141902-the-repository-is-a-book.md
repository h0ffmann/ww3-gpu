# The repository is a book

ADR-0003: "The repository is a book in progress, compiled from the repository, on agentic coding
and agentic research" `(v)`. The lessons of `course/` are its chapters and each release is an
edition. A chapter that contradicts the code is a bug in the chapter.

What the book teaches is held to the same gates as the code: [[202610141900-bit-for-bit-is-the-gate]].
The book remembers across sessions through [[202610141907-long-term-memory-is-ai-memory]].
