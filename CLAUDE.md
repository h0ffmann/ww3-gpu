# ww3-gpu: notes for coding agents

Read `CONTRIBUTING.md` first. Its opening section, "Who this repository is for", applies to every
task: the first readers are scientists (PhD researchers, postdocs and independent researchers in
wave modelling, numerical methods and HPC), so write for a specialist, carry evidence with `(v)`
and `⚠`, and give the command that reproduces every number. The proposal (`pubs/proposal/`) and
`/eli5` are the two named exceptions.

Repo skills live in `.claude/skills/`; each one restates the audience rule for its own job.
