## 4. The kernel port: `W3SNL1` / `INSNL1`

Source of truth: `WW3/model/src/w3snl1md.F90` at the pinned submodule revision (7.14,
`develop`). Phase-1 rules from `docs/AGENTS_KOKKOS_202609.md` §1 apply: translate, do not
improve; float32 state; `LayoutLeft` at the boundary; no allocation in kernels.

- **Tables** (`INSNL1`): the DIA offsets and weights depend only on `NK`, `NTH`, `XFR`, `LAM`
  and the `SNLC1`, `SNLS*` constants. `snl1_tables` computes them on host into `View`s
  once per grid; they are shared by every point and every member.
- **Kernel** (`W3SNL1`): input action spectrum `A(NTH,NK)` per point, group velocity
  `CG(0:NK+1)`, `KDMEAN`; outputs `S(NTH,NK)` and diagonal `D(NTH,NK)`. `parallel_for` over
  points with a `TeamPolicy`, team loop over the extended spectral index; scratch views for
  the extended spectrum (`UE`) and the four quadruplet contributions. Gather formulation, no
  atomics. Kernel label `"srce.snl1.dia"`.
- **Shim**: `extern "C" ww_snl1_init(nk, nth, xfr, lam, ...)` and
  `ww_snl1(npts, a, cg, kdmean, s, d)`; unmanaged host views over the Fortran arrays; phase-1
  copy-in/copy-out to the device state. Fortran side: `w3kokkosmd.F90` with the interface
  blocks and a runtime flag `WW_KOKKOS_SNL1` (environment variable, read once at init).
  The Fortran caller in WW3 is **not** edited in this repo; the module and a documented
  three-line patch (behind a `KOKKOS` switch) live in `kokkos/src/fortran_iface/PATCH.md`
  so the fork submodule can carry it on a branch later.
- **Fixtures**: `gen_snl1_fixture.F90` links against WW3's `ww3_lib` (CMake target
  `WW3::WW3`, built by `just build`), sets up a small grid (`NK=25, NTH=24, XFR=1.1`), calls
  `INSNL1` and `W3SNL1` on JONSWAP spectra at three depths, and writes binary fixtures
  (inputs, tables, `S`, `D`). Fixtures are committed (a few KB) so CI runs parity without WW3.
- **L1 tests** (GoogleTest, run by `ctest` in CI, Serial preset with bounds check):
  tables identical to the fixture (integers exact, weights `1e-6` relative); kernel `S` and
  `D` within `1e-5` relative of the Fortran fixture; action conservation of the DIA term to
  round-off; OpenMP preset gives the same result as Serial to `1e-6`.
- **L2 replay** (manual, needs a WW3 build): `L2_replay.sh <regtest>` runs
  `regtests/ww3_ts1` (or the lab's `switch_lab_shrd` case) twice and calls the comparator.
  Documented in lesson 12 and recorded in `PORT_STATUS.md` with the timing line. Without the
  WW3 caller patch applied, L2 is documented as "pending fork branch"; the script and the
  comparator are complete and tested on two Fortran-only runs (should be identical).

## 5. Comparator: `nccmp-tol`

C++ CLI on `netcdf-c`: `nccmp-tol ref.nc test.nc tolerances.txt`. For each variable listed in
the tolerances file (`name abs rel`, comments with `#`), computes max-abs, RMS and max-rel
differences over non-fill values, prints one table row, exits 0 only if every variable is
within tolerance. Unlisted variables are reported, not judged. Default tolerance file
`kokkos/tools/nccmp-tol/tolerances.txt` with `hs`, `fp`, `dir`, `dp`, `t0m1` rows. Unit tests
generate two small NetCDF files in a temp dir and check the verdict both ways. This is
proposal deliverable "comparador por campo".

## 8. Tooling and CI

- All builds run in `nix develop nix-config/labs/pratico#ww3` (CUDA preset in `#cuda`).
- `ci.yml`: install Nix (Determinate action, as `pubs.yml`'s publisher action does), then
  `just kokkos-test serial-debug`, `just kokkos-test openmp-release`, Fortran compile checks,
  shellcheck, lychee. Pubs workflow unchanged.
- `README.md`: layout table, the new `just` targets, the "way more C++ than Python" stance, the
  proposal link.

## 9. Assumptions and flags

- `scripts/book_prep.py` and `scripts/translate_md.py` remain: they are publishing tooling
  bound to the pandoc pipeline, not lab code. If the owner wants zero Python anywhere,
  `book_prep.py` (51 lines) can become a shell script in a follow-up; `translate_md.py` cannot
  without dropping the translation feature.
- The WW3 fork submodule is not modified in this work; the caller patch is documented, so L2
  parity with the Kokkos path on is deferred to a fork branch. L1 parity against Fortran
  fixtures is the completion criterion here.
- The CUDA preset is built and run only on the owner's RTX 4090 host; CI covers Serial and
  OpenMP.
- Course language stays English; the proposal and mind maps stay Portuguese.

## 10. Verification (definition of done)

1. `just kokkos-test serial-debug` and `just kokkos-test openmp-release` pass in the pratico shell.
2. `git ls-files '*.py'` lists only the two publishing scripts.
3. `cloc`-style count: C++ lines ≥ 2 500; Fortran unchanged or more.
4. `just book` builds; every lesson link resolves (`book_prep.py` exit 0).
5. `ci.yml` green on the PR; nix-config PR green (`nix flake check` in `labs/pratico`).
6. `PORT_STATUS.md` has the `W3SNL1` row with L1 parity numbers and Serial/OpenMP timings.
