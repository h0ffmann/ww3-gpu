# Plans

One dated plan per medium or large change, `YYYY-MM-DD-NNN-<slug>-plan.md`. A plan names the
routine or cost it attacks, the profile row that ranks it (ADR-0002), the static parity argument it
will make and the regtest it leaves for the validation phase. It is read-only once the work starts;
git says whether it shipped. The evidence rule of `CONTRIBUTING.md` applies: `(v)` with what was
checked, `⚠` when it was not, and every number with the command that reproduces it.
