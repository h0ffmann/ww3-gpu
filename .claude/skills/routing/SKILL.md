**Audience.** What `route` returns is a locator, not evidence: the answer to a scientist still
cites the `file:line` it read (`(v)`), and a WW3 fact cites `model/src/<file>.F90:<line>` at the
pin (`just src-st`), never the route output or memory.

# routing

The ww3-gpu adaptation of marola's MIP-0084 (one `route` tool any session can call with nothing
installed) and MIP-0085 (an index per kind of question: doc↔code, decisions). One repository, so
`scripts/route.py` builds its indexes from `git ls-files` on each call, in well under a second;
there is no bundle, no graph to build and no hook. Python 3 standard library only, so it works in a
cloud session, a jail and Kimi Code or Antigravity alike (this directory is also `.agents/skills`).

## One question, one call

```bash
python3 scripts/route.py term NL1             # the GLOSSARY.md row, not its 200 KB
python3 scripts/route.py where W3SDS4         # definition: our C++/shell/Python/just/CMake/Fortran, then WW3/model/src
python3 scripts/route.py docs snl1_shim.cpp   # pages that name a file or symbol, with their section
python3 scripts/route.py why "widen tolerance"    # best-matching paragraphs of docs/, notes/, port reports (BM25)
python3 scripts/route.py section docs/AGENTS_KOKKOS_202609.md 1.5   # one section, not the file
```

`just route …` is the same. Output stops at 40 lines (`--budget N`) and says how many it cut;
narrow the question before widening the budget. `where` says when `WW3/` is not checked out
(`git submodule update --init --depth 1 WW3`). Nothing found exits 1.

## Which source answers what

| Question | Ask |
|---|---|
| The rules, where a change goes, which gate it needs | `AGENTS.md` (already loaded); a section of `CONTRIBUTING.md` with `route section` |
| What an abbreviation, switch, routine or tool name means | `route term <name>` |
| Is this idea already designed or decided | `just adrs`, `docs/WFIPs/README.md`; `route why "<words>"` for the paragraph |
| What was tried before, including failures | `route why "<words>"` (docs/log is in its index); `notes/index.md` |
| What is translated, ported, regtested; what is next | `kokkos/PORT_STATUS.md`, `kokkos/PORT_RANKING.md`, the ledger `kokkos/ports.tsv` |
| A measured number, its machine and command | `bench/README.md`, `bench/results/*.json`; `just results table` |
| The WW3 pin this checkout builds against | `just src-st` |
| A WW3 routine or line | `route where <ROUTINE>`, then read around that line |
| Which page explains this file | `route docs <file>` |
| A proposal reference and how it was checked | `pubs/proposal/REFERENCES.md`; `just refs` |
| The numbers the website shows | `site/data/*.tsv` (generated by `scripts/port_score.py --write`, never edited) |
| What past sessions did | `ai-memory search "<question>"` on the owner's workstation; `MEMORY.md` says what lives where |

## Habits that keep the context small

- Never grep the whole tree: `WW3/`, `WW3-noaa/`, `WW4/` and `picasso/` are read-only submodules
  far larger than the repository. Scope a search to a directory, and search `WW3/model/src` only
  for a Fortran routine.
- Read a large file around a hit (`offset`/`limit`, or `route section`), never whole. The largest
  text files are `docs/GLOSSARY.md` (~220 KB), the plans in `docs/` (30–55 KB) and
  `kokkos/src/fortran_iface/st4_shim.cpp`.
- A generated file (`site/data/`, `kokkos/PORT_STATUS.md`, `docs/WFIPs/README.md`) is refreshed by
  its script, never edited and rarely worth reading whole.
