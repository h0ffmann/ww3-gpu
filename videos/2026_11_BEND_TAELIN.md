# Bend: A Linear Proof Language That Matches C Performance and Runs on GPUs

- Speaker: Victor Taelin.
- Video: https://www.youtube.com/watch?v=PqufdZ5skWQ
- Indexed: 2026-11-20.

The talk shows a language that runs on GPUs with no explicit kernels, and keeps C-level speed
through linear proofs. It is a reference for the language layer of the port: what a GPU runtime
can give a numerical model beyond Kokkos.
